# sip 

A lightweight macOS menu bar app that reminds you to drink water on an interval.

## Features

- Set a custom reminder interval (5–180 min)
- Native notification when it's time to drink water
- Silent mode — mute the notification sound
- Auto-pauses when you're idle
- Auto-pauses while watching something in Stremio, resumes shortly after you switch back
- Clean, minimal menu bar UI; no dock icon, no window clutter

## Tech stack

Swift + SwiftUI, macOS only
