# sip

A menu bar water reminder for macOS.

## Features

- Set a reminder interval and get notified to drink water
- Silent mode for notifications without sound
- Auto pauses when you're idle
- Auto pauses while Stremio is open, resumes shortly after you switch away

## Install

Download `sip.zip` from the [latest release](https://github.com/arajenk/sip/releases/latest), unzip, move `sip.app` to Applications.

Not notarized, so right click and Open on first launch. It'll also ask for Accessibility permission, needed to detect idle time.
